Statische JSON API · v1

Einfach.
Offen.

Die API besteht aus statischen JSON-Dateien. Sie braucht keinen Schlüssel, hat keine serverseitigen Limits und kann direkt aus Browsern und Apps gelesen werden.

Endpunkte

GET/api/v1/episodes.json
GET/api/v1/episodes/index.json
GET/api/v1/episodes/{nummer}.json
GET/api/v1/status.json
SPEC/api/openapi.json

Beispiel

const response = await fetch(
  "https://ciavland.github.io/benjamETAin/api/v1/episodes/001.json"
);
const episode = await response.json();
console.log(episode.title);

Versionierung

/api/v1/ bleibt kompatibel. Brechende Schemaänderungen erhalten eine neue Hauptversion. Für reproduzierbare Builds kann zusätzlich eine bestimmte Git-Version über jsDelivr referenziert werden:

https://cdn.jsdelivr.net/gh/ciavland/benjamETAin@<tag>/data/all.json

Das Datenmodell ist im JSON Schema dokumentiert. Rechtliche Hinweise stehen in DATA-LICENSE.md.
